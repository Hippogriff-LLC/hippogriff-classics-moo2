# Reverse-Engineering / Reimplementation Boundary

The project is a new implementation informed by behavioral study and reverse engineering.

Permitted repository material includes independently authored observations, file-format descriptions, compatibility notes, tests, algorithms, interfaces, and implementation code.

Do not commit original proprietary binaries/data or bulk decompiler/disassembly output that reproduces copyrighted program material.

Research tooling may inspect operator-supplied files outside Git. Derived specifications should describe behavior and formats rather than serve as a redistribution channel for original code or content.

Provenance for meaningful external research should be recorded under `provenance/`.
